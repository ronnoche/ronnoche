My Vim Motions Cheatsheet

January 18, 2024
Tech

Mastering Vim motions is fundamental to becoming efficient in navigating and editing text. Motions define how you move through text, and when combined with commands like d (delete), c (change), or y (yank), they enable you to perform precise and powerful edits with minimal keystrokes.

This is my personal cheatsheet of Vim motions based on what I usually use on a daily basis:

Basic Motions

  • h – Move left
  • l – Move right
  • j – Move down
  • k – Move up
  • 0 – Move to the beginning of the line
  • ^ – Move to the first non-blank character of the line
  • $ – Move to the end of the line
  • gg – Move to the start of the file
  • G – Move to the end of the file
  • :n – Move to line n (e.g., :42 moves to line 42)

Word Motions

  • w – Move to the start of the next word
  • W – Move to the start of the next WORD (ignores punctuation)
  • e – Move to the end of the current/next word
  • E – Move to the end of the current/next WORD
  • b – Move to the beginning of the previous word
  • B – Move to the beginning of the previous WORD

Paragraph Motions

  • { – Move to the beginning of the current/previous paragraph
  • } – Move to the beginning of the next paragraph

Search Motions

  • /pattern – Search forward
  • ?pattern – Search backward
  • n – Repeat last search (same direction)
  • N – Repeat last search (opposite direction)
  • * – Search forward for word under cursor
  • # – Search backward for word under cursor

Character Search Motions

  • f{char} - Move forward to {char}
  • F{char} - Move backward to {char}
  • t{char} - Move forward before {char}
  • T{char} - Move backward after {char}
  • ; - Repeat last character search
  • , - Repeat last character search in the opposite direction

Text Objects

Text objects allow you to select and manipulate blocks of text efficiently:

  • iw - Inner word
  • aw - A word (including trailing space)
  • i', a' - Inside / Around single quotes
  • i", a" - Inside / Around double quotes
  • i(, a( - Inside / Around parentheses
  • ...and many more for brackets, braces, and HTML tags.

Combining Motions with Commands

Combine motions with commands for efficient editing:

  • dw - Delete to the start of the next word
  • d$ - Delete to the end of the line
  • ciw - Change inside the current word
  • yip - Yank inner paragraph
